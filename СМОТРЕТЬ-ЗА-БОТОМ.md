# Смотреть за ботом живьём

Три способа увидеть одно и то же: что написал клиент, что ответил живой оператор,
что ответил бы бот и **почему** он так решил.

## 1. Двойной клик

| Файл | Что делает | Стоит ли денег |
|---|---|---|
| `Учебный-прогон.command` | прогон по живым диалогам корпуса | по умолчанию нет (запись эталона) |
| `Смотреть-бота.command` | живой поток с боевого сервера | нет |

## 2. Из терминала

```bash
# бесплатно, по замороженной выборке эталона
uv run python analysis/replay.py 5 --кассета --пауза 1 2>/dev/null | uv run python analysis/watch.py

# на свежих диалогах корпуса — живые вызовы модели, это платно
uv run python analysis/replay.py 5 --пауза 1 2>/dev/null | uv run python analysis/watch.py

# боевой поток
ssh leadchat-watch 'touch /opt/leadbot/data/shadow.jsonl; tail -n 40 -F /opt/leadbot/data/shadow.jsonl' | uv run python analysis/watch.py
```

## Как читать экран

```
═══ 02:02:52 · учебный-1 · Москва · MNC ══════════════════════════════
 учебный прогон по корпусу
 КЛИЕНТ     Доброе утро! Нужно в садике 14 помыть окна в группе
 ОПЕРАТОР   Здравствуйте, когда вам было бы удобно?
 БОТ        здравствуйте, сделаю. Подъеду через час-полтора, удобно
            вам будет? Куда подъехать?
 ПОЧЕМУ     СТАДИЯ ВХОД: первое касание · claude-haiku-4-5 · 37 мс
            не хватает: city, phone, address, service, preferred_time
            → только бот назвал время приезда
            → только бот спросил адрес
            ✓ оба задал вопрос
            длина 82 против 39 у живого (медиана 39)
```

* **БЫЛО** — прошлая подсказка бота, если она была. По ней видно, повторяется он или нет.
* **ПОЧЕМУ** — стадия воронки, слой, который решил ход, время ответа и чего боту не хватает.
* Последние строки — **сверка с живым**: `→ только бот` значит бот сделал шаг, которого
  человек не делал; `← только оператор` — наоборот, бот шаг пропустил.

## Где живёт журнал

`data/shadow.jsonl` на сервере бота, одна строка JSON на ход, ротация по 20 МБ.
Телефоны маскируются до последних четырёх цифр. Выключается `LEADBOT_SHADOW=0`.

Журнал не имеет права мешать работе: любая ошибка записи гасится молча — наблюдение
не стоит ни одного потерянного ответа клиенту.

## Чем это отличается от эталона

`analysis/benchmark.py` даёт **число** (общий балл, доля чистых ходов, дисциплина
молчания) — по нему видно, стало лучше или хуже. Смотрелка даёт **картину**: почему
конкретный ход именно такой. Число говорит «где», картина — «что чинить».
