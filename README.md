# Лид-бот

ИИ-мастер для чатов Авито: ведёт клиента как частный мастер по ремонту — строго
по регламенту компании — и доводит разговор до заявки в CRM. Работает в двух
режимах: подсказывает ответы оператору в «Пульте» (человек отправляет сам) или
отвечает клиенту сам в связке с [LeadChat](https://github.com/goldshell88-maker/leadchat).

## Как думает

Каждый ход проходит четыре слоя — от дешёвого к дорогому:

1. **Правила** (без обращения к модели): отказы по видам работ, темы для
   согласования, жалобы и статусные вопросы — сразу человеку, мусор, созвоны.
2. **Свой классификатор намерений** — наивный Байес на корпусе компании
   (цена, выезд, формат работы и другие).
3. **Примеры** — пары «вопрос клиента → лучший ответ» из успешных диалогов; на
   каждый ход бот видит несколько ближайших.
4. **Модель** — по сложности хода, с плейбуком регламента.

Поля будущей заявки (что сломалось, адрес, время, телефон) копятся по ходу
разговора; филиал подбирается по адресу и карте зон.

## Что где

| Путь | Что внутри |
|---|---|
| `brain/server.py` | сервис «мозга»: HTTP на 127.0.0.1, только стандартная библиотека Python |
| `brain/prefilter.py`, `brain/territory.py` | правила первого слоя, города и зоны филиалов |
| `brain/prompt.py`, `brain/rag.py` | плейбук для модели и подбор примеров |
| `brain/crm.py`, `brain/escalation.py` | черновик заявки и передача человеку |
| `brain/leadchat.py`, `brain/jivo_live.py` | связка с LeadChat и приём из Jivo |
| `ui/` | «Пульт», панель, страница разметки диалогов |
| `ui/crm-extension/` | расширение Chrome, которое заводит заявки в CRM на рабочем ПК |
| `mac/` | установка и запуск на Mac |
| `docs/` | интеграция с LeadChat и решения по регламенту |

## Запуск

```bash
cp config.example.json config.json   # адрес шлюза модели, токен, модель
mac/setup-mac.command                # Python 3, зависимости, проверка путей
mac/Start-bot.command                # Пульт: http://localhost:8789/relay
```

В бою бот работает службой на отдельном сервере за Caddy; панель — по ссылке с
токеном из окружения сервера.

## Чего здесь нет

Корпус диалогов, эталонные пары для примеров (`brain/rag_examples.json`), журналы
заявок и исследования в `analysis/` — это живая переписка клиентов, в репозиторий
они не выгружаются. Без эталонных пар бот запускается, но слой примеров пуст и
ответы беднее; пары и корпус кладутся рядом отдельно.
