Привязать аккаунт

client_id и client_secret берутся в кабинете Avito: Профиль → Для профессионалов → Интеграции → Ключи API. Секрет хранится только на этом сервере и никуда, кроме api.avito.ru, не уходит. У каждого аккаунта — свой постоянный «голос» (персона), чтобы клиент, пишущий на несколько аккаунтов, видел разных мастеров.
Объявление → направление / партнёр / город / голос. Реестр наполняется сам из входящих чатов; неразмеченные строки подсвечены — у них направление берётся из настроек аккаунта.
