# Переезд «Лид-бота» на Mac

## Коротко

1. Скопируй архив `Лид-бот-перенос-<дата>.zip` на Mac (AirDrop / флешка / облако).
2. Распакуй на **Рабочий стол**. Внутри две папки: `Лид-бот` и `Jivo Webhook` — они должны лежать **рядом**.
3. Открой `Лид-бот/mac/` и запусти **`setup-mac.command`** двойным щелчком.
4. После установки — **`Start-bot.command`**. Откроется Пульт: `http://localhost:8789/relay`.

Если macOS ругается «неизвестный разработчик»: правый клик по файлу → **Открыть** → **Открыть**.
Либо один раз в Терминале: `xattr -dr com.apple.quarantine ~/Desktop/Лид-бот`

---

## Что делает setup-mac.command

| Шаг | Что ставит | Зачем |
|---|---|---|
| 1 | Homebrew | пакетный менеджер, если его ещё нет |
| 2 | Python 3 | на нём весь мозг (нужен 3.9+) |
| 3 | Pillow | сжимает фото перед отправкой в модель — без него фото дороже |
| 4 | — | проверяет `config.json`, находит корпус, показывает пути |
| 5 | ярлыки | `Start-bot`, `Merge-dialogs`, `Run-tests` |
| 6 | launchd | ежечасная склейка диалогов (замена задачи планировщика Windows) |

Никаких внешних библиотек мозг не требует — только стандартная библиотека Python и опциональный Pillow.

---

## Ярлыки в папке `mac/`

- **`setup-mac.command`** — установка (запускается один раз).
- **`Start-bot.command`** — поднимает сервер и открывает Пульт. Останавливается закрытием окна.
- **`Merge-dialogs.command`** — склейка кусков диалогов в полные (обычно идёт сама раз в час).
- **`Run-tests.command`** — локальные тесты, **денег не стоят** (шлюз не дёргается): 48 юнитов гардов,
  озвучки цен, фильтр мусора. Первое, что стоит запустить после переезда.

Тесты, которые ходят в модель и стоят денег, — отдельно: `bash analysis/_run_all.sh`
(шлюз пускает максимум 2 запроса параллельно, иначе 429).

## Переход на прямой API Anthropic вместо шлюза

Правь `config.json` в корне проекта:

```json
"gateway_base": "https://api.anthropic.com",
"auth_token":   "sk-ant-твой-ключ"
```

Стиль авторизации переключится сам: для `api.anthropic.com` и ключей `sk-ant-…` уйдёт заголовок
`x-api-key`, для шлюза — `Bearer`. Можно ничего не править в файле, а задать окружением:

```bash
export LEADBOT_API_BASE=https://api.anthropic.com
export LEADBOT_API_KEY=sk-ant-...
```

Переменные окружения перекрывают `config.json`. Принудительно задать стиль: `LEADBOT_AUTH=x-api-key` или `bearer`.

⚠ Модели в `config.json` (`claude-sonnet-5`, `claude-haiku-4-5-20251001`) при переходе на прямой API
проверь на актуальность — имена у шлюза и у Anthropic могут отличаться.

## Где что лежит

```
Рабочий стол/
├── Лид-бот/
│   ├── brain/          мозг: server.py, prompt.py (плейбук), prefilter.py (роутеры), rag.py, paths.py
│   ├── analysis/       тесты, майнинг корпуса, сборка RAG-пула, петля обучения
│   ├── ui/             Пульт оператора, окно оператора, страница разметки /review
│   ├── mac/            ярлыки для macOS (эта папка)
│   └── config.json     ⚠ ТОКЕН ВНУТРИ — архив никому не пересылать
└── Jivo Webhook/
    └── data/
        ├── dialogs_merged/   ПОЛНЫЕ диалоги — основной корпус (~4900 шт)
        ├── raw/              сырые вебхуки — источник истины для пересборки
        └── dialogs/          свежие куски от приёмника (пустеет после склейки)
```

Пути больше **не прописаны жёстко**: `brain/paths.py` находит корпус сам — по переменной
`LEADBOT_WEBHOOK_DIR`, потом по `jivo_webhook_dir` из `config.json`, потом по соседней папке
«Jivo Webhook». Проверить, что нашлось: `python3 brain/paths.py`.

Если держишь корпус в другом месте:

```bash
export LEADBOT_WEBHOOK_DIR="/Users/ты/куда-то/Jivo Webhook"
```

## Чего в архиве НЕТ и почему

- **`ngrok.exe`** — windows-бинарник. Если понадобится туннель для приёмника Jivo,
  ставь маковый: `brew install ngrok`.
- **Приёмник Jivo сам по себе не запущен.** Он нужен, только если на Mac будут приходить живые вебхуки.
  Для работы с уже собранным корпусом (анализ, тесты, Пульт, разметка) он не требуется.
- **Старые резервные `dialogs.jsonl.old_*`** — включены только в «полный» архив; они нужны
  исключительно для аварийной пересборки корпуса (`merge_dialogs.py --rebuild`).

## Быстрая проверка после переезда

```bash
cd ~/Desktop/Лид-бот
python3 brain/paths.py          # покажет, где нашёлся корпус
python3 analysis/test_router_guards.py   # должно быть 48/48
```

Если `paths.py` пишет «НЕТ» напротив корпуса — папка «Jivo Webhook» лежит не рядом с проектом.
